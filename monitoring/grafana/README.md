# FreightFlow Grafana Dashboards

Import the JSON files in `dashboards/` into Grafana and map the Prometheus data
source UID to `prometheus`, or update the `datasource.uid` fields to match the
target workspace.

Dashboards included:

- `api-dashboard.json`
- `auth-dashboard.json`
- `queue-dashboard.json`
- `shipment-dashboard.json`
